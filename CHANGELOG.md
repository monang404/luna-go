## [0.1.0] - 2026-08-20
### Added
- First public release of `luna-go`.
- Multi-provider LLM support (Anthropic, OpenRouter, Groq, Gemini, Cerebras).
- Robust Permission System for local execution security.
- Agent and Subagent engine capability.
- Integrated Web Search via DuckDuckGo Lite Scraper.
- Session Resume & Memory functionality.
- Asynchronous update checking on CLI startup.
- Multi-platform binary releases (macOS, Linux, Windows).
